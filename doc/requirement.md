# 任务管理应用 — 需求文档

## 1. 概述

一款浏览器端的轻量任务管理工具，采用看板视图组织任务。用户可以在页面中增删改查任务，通过拖拽快速变更任务状态，设置截止日期并按优先级排序，并享受深色模式体验。所有数据存储在浏览器本地，刷新不会丢失。

## 2. 功能需求

### FR-01 任务创建
| 项目 | 说明 |
|------|------|
| 触发 | 点击页头「新建任务」按钮 |
| 交互 | 弹出模态框，填写标题、描述、截止日期 |
| 标题 | 必填，非空校验，否则无法提交 |
| 描述 | 选填，纯文本 |
| 截止日期 | 选填，日期选择器 (`input[type="date"]`) |
| 优先级 | 下拉选择：高 / 中 / 低，默认中 |
| 状态 | 下拉选择：待办 / 进行中 / 完成，默认待办 |
| 保存 | 点击保存后关闭弹窗，卡片出现在对应列 |
| 取消 | 点击弹窗外区域或关闭按钮取消，不保存 |

### FR-02 任务读取与展示
- 页面加载时从 localStorage 读取所有任务
- 按状态分三列展示：**待办** / **进行中** / **完成**
- 每列顶部显示列名和当前任务数量
- 每张卡片显示：标题、优先级色标、描述预览（截断）、**截止日期**、创建时间
- **逾期标记**：已过截止日期的卡片增加红色边框和「⚠️ 逾期」标识
- **同列排序**：卡片按 `order` 字段排序（数值越小越靠前），新建任务默认排到最前
- 优先级颜色标识：高=红色 / 中=黄色 / 低=绿色

### FR-03 任务编辑
- 点击卡片任意区域打开编辑弹窗
- 表单预填当前数据，可修改标题、描述、**截止日期**、优先级、状态
- 保存后立即更新卡片内容和列位置（若状态改变）
- 标题仍做非空校验

### FR-04 任务删除
- 编辑弹窗中提供「删除」按钮
- 点击后弹出**自定义确认对话框**（非原生 `confirm()`），确认后删除
- 删除后显示「已删除」toast，提供「撤销」按钮（3 秒内可撤销）
- 3 秒后真正从 localStorage 移除
- 对应列立即移除该卡片并更新计数

### FR-05 看板拖拽与列内排序
- 所有卡片可通过鼠标拖拽移动（Pointer Events 方案）
- **跨列拖拽**：拖拽到其他列的放置区松开后，任务状态自动更新
- **同列排序**：在同一列内拖拽卡片可调整顺序，释放后更新 `order` 值
- 源列和目标列的卡片列表及计数实时刷新
- 拖拽过程中列应有视觉高亮反馈
- **触屏降级**：触屏设备上不显示拖拽效果，改为卡片上「⋮」菜单 → 移动至其他状态

### FR-06 深色模式
- 页头提供一键切换按钮（🌙 / ☀️ 图标）
- **首次访问**：自动检测系统主题偏好（`prefers-color-scheme`），默认跟随系统
- 用户手动切换后，偏好保存到 localStorage，覆盖系统默认
- **系统主题变化时**：若用户未手动覆盖过，自动跟随系统切换
- 再次打开页面时自动恢复上次选择的主题

### FR-07 搜索与筛选
- 页头右侧提供搜索输入框
- 输入即搜索，实时过滤
- 按标题和描述做模糊匹配（大小写不敏感）
- 搜索激活时，所有列仅显示匹配的卡片，列计数更新为匹配数
- 清空搜索框恢复完整看板

## 3. 非功能需求

| 类型 | 要求 |
|------|------|
| 持久化 | 所有任务数据和主题偏好存储在 localStorage，页面刷新不丢失 |
| 兼容性 | 支持现代浏览器（Chrome / Firefox / Safari / Edge 最近两个大版本） |
| 性能 | 纯前端无网络请求，CRUD 操作响应 < 50ms |
| 可维护性 | JS 按功能拆分为独立模块，CSS 使用自定义属性管理主题，模块间通过事件总线解耦 |
| 无障碍 | 表单字段有对应 label，拖拽卡片有 aria 提示，键盘可操作 |
| 安全性 | localStorage 操作捕获 QuotaExceededError，界面显示 toast 提示 |

### 4.2 卡片设计
- 左上角圆形色块表示优先级（🔴高 🟡中 🟢低）
- 标题加粗显示
- 描述文字用浅色、单行截断加省略号
- 截止日期显示在底部，格式 `MM-DD`，逾期时红色加 ⚠️ 前缀
- 底部小字显示创建日期，格式 `YYYY-MM-DD`
- 悬停时有轻微阴影上浮效果
- 触屏设备右下角显示「⋮」操作菜单按钮

### 4.3 弹窗设计
- 居中弹窗，半透明黑色遮罩背景
- 支持三种模式：**新建任务** / **编辑任务** / **确认对话框**
- 新建/编辑表单字段：标题（输入框）、描述（文本域）、截止日期（日期选择器）、优先级（下拉）、状态（下拉）
- 确认对话框：消息文本 + 确认/取消按钮
- 底部按钮：保存 + 删除（仅编辑模式显示）

### 4.4 空状态
- 某列无任务时显示占位文字「暂无任务」
- 全部三列都空时（首次使用），自动创建以下示例任务并显示简短引导提示：
  | 标题 | 描述 | 优先级 | 状态 | 截止日期 |
  |------|------|--------|------|---------|
  | 欢迎使用 Task Manager | 试试拖拽我到其他列 🚀 | 低 | 待办 | — |
  | 添加第一个真实任务 | 点击上方「新建任务」开始 | 中 | 待办 | 次日 |
  | 探索深色模式 | 点击页头的 🌙 按钮切换 | 低 | 完成 | — |

### 4.5 深色模式配色
| 角色 | 浅色 | 深色 |
|------|------|------|
| 背景 | #f4f5f7 | #1a1a2e |
| 卡片 | #ffffff | #16213e |
| 列头 | #e2e4e6 | #0f3460 |
| 文字 | #172b4d | #e0e0e0 |
| 次要文字 | #5e6c84 | #a0a0a0 |
| 逾期标记 | #e74c3c | #ff6b6b |

### 4.6 Toast 通知
- 右下角浮动显示，3 秒自动消失
- 删除时显示「已删除」+「撤销」按钮
- 容量不足时显示警告提示
- 支持同时多条堆叠

## 5. 验收标准

1. [ ] 打开页面看到三列看板，标题为「Task Manager」
2. [ ] 首次访问时深色模式自动跟随系统偏好
3. [ ] 点击「新建任务」弹出表单，填写标题（必填）+ 截止日期（选填）可创建任务
4. [ ] 创建后卡片出现在正确的列，列计数更新
5. [ ] 同列内卡片可按自定义顺序排列
6. [ ] 点击卡片可编辑标题、描述、截止日期、优先级、状态
7. [ ] 编辑弹窗中有「删除」按钮，自定义确认对话框确认后删除
8. [ ] 删除后出现「撤销」toast，3 秒内可恢复
9. [ ] 拖拽卡片到其他列，状态改变且两列计数更新
10. [ ] 同一列内拖拽可调整卡片顺序
11. [ ] 触屏设备上卡片显示「⋮」菜单，可通过菜单移动状态
12. [ ] 设置截止日期后，过期卡片显示逾期标记
13. [ ] 点击深色模式按钮，全局切换到深色，刷新后保留
14. [ ] 系统深色模式变化时，若未手动覆盖则自动跟随
15. [ ] 搜索框输入文字，实时过滤各列卡片
16. [ ] 刷新页面后，所有任务和主题偏好保留
17. [ ] 空列显示「暂无任务」，首次使用自动创建示例任务
