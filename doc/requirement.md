# 任务管理应用 — 需求文档

## 1. 概述

一款浏览器端的轻量任务管理工具，采用看板视图组织任务。用户可以在页面中增删改查任务，通过拖拽快速变更任务状态，设置截止日期和优先级，并享受深色模式体验。所有数据存储在浏览器本地，刷新不会丢失。

## 2. 功能需求

### FR-01 任务创建
| 项目 | 说明 |
|------|------|
| 触发 | 点击页头「+ 新建任务」按钮 |
| 交互 | 弹出模态框，填写标题、描述、截止日期 |
| 标题 | 必填，非空校验，否则无法提交 |
| 描述 | 选填，纯文本 |
| 截止日期 | 选填，`input[type="date"]` 日期选择器 |
| 优先级 | 下拉选择：高 / 中 / 低，默认中 |
| 状态 | 下拉选择：待办 / 进行中 / 完成，默认待办 |
| 保存 | 提交后关闭弹窗，卡片出现在对应列末尾（按 `order` 值排列） |
| 取消 | 点击弹窗外遮罩区域或右上角关闭按钮取消，不保存 |

### FR-02 任务读取与展示
- 页面加载时从 localStorage 读取所有任务
- 按状态分三列展示：**待办** / **进行中** / **完成**
- 每列顶部显示列名、当前任务数量；若有逾期任务，额外显示 `⚠️N`（警示符号加数字，不含「逾期」文字）
- 每张卡片显示：标题、优先级文字标签、描述预览（最多两行截断）、截止日期、创建日期
- **逾期标记**：已过截止日期的卡片，截止日期文字变红色并添加 `⚠️` 前缀
- **同列排序**：卡片按 `order` 字段升序排列，同 order 时按创建时间降序；新建任务默认排到列末尾
- 优先级颜色：高=红色 / 中=黄色 / 低=绿色（背景色 + 文字色）

### FR-03 任务编辑
- 点击卡片任意区域打开编辑弹窗
- 表单预填当前数据，可修改标题、描述、截止日期、优先级、状态
- 保存后立即更新卡片内容和列位置（若状态改变）
- 标题仍做非空校验

### FR-04 任务删除
- 编辑弹窗中提供「删除」按钮
- 点击后先弹出**自定义确认对话框**，确认后才执行删除
- 确认后卡片立即从看板消失（由过滤计算属性驱动，Vue 移除对应的卡片 DOM 节点），显示「已删除」toast +「撤销」按钮
- 3 秒内点击撤销，卡片恢复显示，数据不变
- 3 秒后未撤销，任务从内存数组和 localStorage 彻底移除
- 若最终写入 localStorage 失败，任务恢复显示并提示存储空间不足

### FR-05 看板拖拽与列内排序
- 使用 Pointer Events 实现拖拽：`pointerdown` 开始追踪，移动超过 5px 后启动
- 拖拽开始时源卡片从布局中隐藏（`display: none`），其他卡片自动补位
- 拖拽过程中鼠标旁跟随一张半透明浮动卡片（旋转 3°、略微放大）
- **跨列拖拽**：放入目标列后更新任务状态，并插入到目标卡片之前（或列末尾）
- **同列排序**：在同一列内拖拽可调整顺序
- 拖拽过程中目标列有背景高亮和内侧环线反馈
- **触屏降级**：触屏设备上不启动拖拽，改为卡片右下角「⋮」菜单 → 移动至其他状态
- 拖拽结束（成功放下、移出窗口、按 Esc 等）后恢复源卡片显示，清理浮动元素

### FR-06 深色模式
- 页头提供一键切换按钮（🌙 / ☀️ 图标）
- **首次访问**：自动检测系统主题偏好（`prefers-color-scheme`），默认跟随系统
- 用户手动切换后，偏好保存到 localStorage（仅保存 `'light'` 或 `'dark'`）
- **系统主题变化时**：仅当用户从未手动切换过（localStorage 无保存值）时自动跟随
- 再次打开页面时，优先读取 localStorage 中的偏好，无保存值时跟随系统

### FR-07 搜索与筛选
- 页头右侧提供搜索输入框
- 输入即搜索，实时过滤
- 按标题和描述做模糊匹配（大小写不敏感）
- 搜索激活时，所有列仅显示匹配的卡片，列计数更新为匹配数
- 清空搜索框恢复完整看板

## 3. 非功能需求

| 类型 | 要求 |
|------|------|
| 持久化 | 任务数据和主题偏好存储在 localStorage，页面刷新不丢失 |
| 兼容性 | 目标支持现代浏览器（Chrome / Firefox / Safari / Edge 最近两个大版本）——未经系统性测试 |
| 性能 | 纯前端无网络请求，CRUD 操作响应预期在可接受范围内——未做精确基准测试，< 50ms 为期望目标而非已验证事实 |
| 可维护性 | 使用 Vue 3 Composition API，组件按功能拆分为独立 `.vue` 文件；Store 通过 `reactive` 管理状态，组件通过 `computed` 响应式读取 |
| 无障碍 | 表单字段有 `<label>` 元素与之对应（通过文本相邻而非 `for` 属性）；任务卡片无 ARIA 角色/属性增强；不支持键盘拖拽——属待改进项 |
| 存储异常 | `_save()` 捕获 `QuotaExceededError` 并触发 `CustomEvent`，`App.vue` 监听后显示 Toast 警告 |

## 4. UI / UX 描述

### 4.1 整体布局（概念示意，非精确像素）
```
┌────────────────────────────────────────────────────────────┐
│  Task Manager        [🔍 搜索…]      [🌙]  [+ 新建任务]   │
├──────────────┬──────────────────┬──────────────────────────┤
│ 📋 待办 (N)  │ 🔄 进行中 (N)    │ ✅ 完成 (N)              │
│ ⚠️X          │                  │                          │
│ ┌──────────┐ │ ┌──────────────┐ │ ┌──────────────────────┐ │
│ │ 高 任务A │ │ │ 中 任务C     │ │ │ 低 任务E             │ │
│ │ 描述…    │ │ │ 描述…       │ │ │ 描述…                │ │
│ │ 📅 09-25 │ │ │ 📅 09-30    │ │ │ 📅 09-25            │ │
│ └──────────┘ │ └──────────────┘ │ └──────────────────────┘ │
│ ┌──────────┐ │                  │                          │
│ │ 中 任务B │ │    暂无任务      │                          │
│ │ 描述…    │ │                  │                          │
│ │ ⚠️ 09-20 │ │                  │                          │
│ └──────────┘ │                  │                          │
└──────────────┴──────────────────┴──────────────────────────┘
```

> 注：以上为概念示意。`⚠️ 09-20` 表示逾期任务的截止日期（红色文字）；已完成任务不会被判为逾期。完整界面可参考 `screenshots/` 目录下的实际截图。

### 4.2 卡片设计
- 左上角圆角文字标签表示优先级（浅色背景 + 深色文字；深色模式下为半透明深色底 + 浅色文字）：`高`（浅红底、深红字）、`中`（浅黄底、深黄字）、`低`（浅绿底、深绿字）
- 标题约 15px 半粗体
- 描述约 14px，最多显示两行（`line-clamp-2`），超出省略
- 截止日期 `MM-DD` 格式；逾期时文字变红 + `⚠️` 前缀
- 创建日期 `YYYY-MM-DD` 格式
- 悬停时轻微阴影上浮（`-translate-y-0.5`）
- 触屏设备右下角显示「⋮」菜单按钮

### 4.3 弹窗设计
- 使用 `<Teleport to="body">` 居中弹窗，半透明黑色遮罩背景
- 支持三种模式：**新建任务** / **编辑任务** / **确认对话框**
- 新建/编辑表单字段：标题（输入框）、描述（文本域）、截止日期（日期选择器）、优先级（下拉）、状态（下拉）
- 确认对话框：消息文本 + 取消/确认删除按钮
- 底部按钮：保存 + 删除（仅编辑模式显示）
- 关闭方式：点击遮罩区域、关闭按钮均可关闭

### 4.4 空状态
- 某列无任务时显示居中灰色文字「暂无任务」
- 全部三列都空时（_包括用户删除所有任务后刷新_），自动创建以下示例任务：
  | 标题 | 描述 | 优先级 | 状态 | 截止日期 |
  |------|------|--------|------|---------|
  | 欢迎使用 Task Manager | 试试拖拽我到其他列 🚀 | 低 | 待办 | — |
  | 添加第一个真实任务 | 点击上方「新建任务」开始 | 中 | 待办 | 次日 |
  | 探索深色模式 | 点击页头的 🌙 按钮切换 | 低 | 完成 | — |

> **限制**：该逻辑在每次 `App.vue` `onMounted` 时执行，并非严格的"仅首次"——用户删光所有任务后刷新页面会再次获得示例任务。

### 4.5 深色模式配色

当前样式由 Tailwind `dark:` 变体实现，控制台实际色值取决于 Tailwind 调色板，大致对应：

| 角色 | 浅色 | 深色 |
|------|------|------|
| 页面背景 | `bg-gray-100` (#f3f4f6) | `#1a1a2e` |
| 列背景 | `bg-white` (#ffffff) + `border-gray-200` | `bg-gray-800/60` + `border-gray-700/40` |
| 卡片背景 | `bg-white` (#ffffff) | `bg-gray-800` (#1f2937) |
| 主要文字 | `text-gray-800` / `text-gray-700` | `text-gray-200` / `text-gray-300` |
| 次要文字 | `text-gray-500` / `text-gray-400` | `text-gray-400` / `text-gray-500` |
| 逾期文字 | `text-red-500` | `text-red-400` |
| 强调色 | `bg-indigo-500` | `bg-indigo-500` |

### 4.6 Toast 通知
- 右下角浮动显示，3 秒自动消失
- 删除时显示「已删除」+「撤销」按钮
- 存储容量不足时显示警告提示
- 支持同时多条堆叠

## 5. 验收标准

以下列出当前实现可支持或部分支持的表述。未经验证的项已标注「待验证」或注明限制。

1. [ ] 打开页面看到三列看板（待办 / 进行中 / 完成）
2. [ ] 首次访问时深色模式自动跟随系统偏好
3. [ ] 点击「+ 新建任务」弹出表单，填写标题（必填）+ 截止日期（选填）可创建任务
4. [ ] 创建后卡片出现在正确列，列计数更新，新卡片在列末尾
5. [ ] 同列内卡片可按自定义顺序拖拽排列
6. [ ] 点击卡片可编辑标题、描述、截止日期、优先级、状态
7. [ ] 编辑弹窗中有「删除」按钮，点击后弹出确认对话框，确认后删除
8. [ ] 删除后卡片立即从看板消失，出现「撤销」toast，3 秒内可恢复
9. [ ] 拖拽卡片到其他列，状态改变且两列计数更新
10. [ ] 同一列内拖拽可调整卡片顺序，刷新后保持
11. [ ] 触屏设备上卡片显示「⋮」菜单，可通过菜单移动状态
12. [ ] 设置截止日期后，过期卡片显示 `⚠️` 逾期标记
13. [ ] 点击深色模式按钮切换主题，刷新后保留选择
14. [ ] 系统深色模式变化时，若未手动切换则自动跟随
15. [ ] 搜索框输入文字，实时过滤各列卡片
16. [ ] 刷新页面后任务和主题偏好保留
17. [ ] 空列显示「暂无任务」；全部为空时自动创建示例任务（含用户删光后刷新的情况）
